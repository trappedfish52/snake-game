## Описание проекта

Программа реализует классическую игру «Змейка» с двумерной анимацией.
Игрок собирает еду и увеличивает счёт, избегая столкновений со стенами и телом.
Графика нарисована самостоятельно средствами tkinter, внешних ресурсов нет.

## Функциональные возможности

### Основной функционал

- Движение по клеточному полю 20 × 20.
- Случайное размещение еды только в свободных клетках.
- Рост змейки, подсчёт очков, проверка столкновений.
- Запрет разворота назад, завершение игры и победа при заполнении поля.

### Дополнительный функционал

- Пауза и перезапуск без закрытия окна.
- Постепенное ускорение игры.
- Разные цвета головы, тела и еды.

## Требования к системе

- Python 3.10 или новее; Windows, macOS или Linux с графическим экраном.
- Стандартные библиотеки: tkinter и random; тесты используют unittest.
- Внешние Python-пакеты не нужны, requirements.txt содержит пояснение.
- Проверка tkinter: `python -m tkinter`. Если модуль отсутствует, установите
  сборку Python с Tcl/Tk; на Ubuntu/Debian пакет называется python3-tk.

## Установка и запуск

### 1. Получение проекта

Распакуйте архив либо после публикации выполните:

```sh
git clone https://github.com/trappedfish52/snake-game.git
cd snake-game
```

Этот адрес предназначен для будущего репозитория, публикация ещё не выполнена.

### 2. Виртуальное окружение

macOS/Linux:

```sh
python3 -m venv venv
source venv/bin/activate
```

Windows (CMD):

```bat
python -m venv venv
venv\Scripts\activate
```

Windows (PowerShell):

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Зависимости и запуск

```sh
python -m pip install -r requirements.txt
python main.py
```

В PyCharm выберите интерпретатор созданного venv. Токены и интернет игре не нужны.

### 4. Управление

| Клавиша | Действие |
| --- | --- |
| Стрелки | Изменить направление |
| Space | Пауза / продолжить |
| R | Новая игра |
| Esc | Закрыть окно |

## Структура проекта

```text
snake_game/
├── README.md
├── .gitignore
├── requirements.txt
├── main.py
├── src/
│   ├── __init__.py
│   ├── model.py
│   └── app.py
└── tests/
    └── test_model.py
```

main.py — точка входа, model.py — класс Snake с правилами, app.py — класс App
с интерфейсом и анимацией. Логика отделена от графики для тестирования без окна.
Для маленькой игры дополнительный слой отрисовки не нужен: его методы входят в App.
Папка venv создаётся локально и по требованию преподавателя не внесена в .gitignore.

## Пример использования

Запустите игру и поверните стрелками к красной еде. После её сбора счёт увеличится
на один, змейка вырастет. Нажмите Space: движение приостановится; повторное нажатие
продолжит игру. Столкнитесь со стеной и нажмите R для новой попытки.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Проверяются рост после еды, столкновения со стеной и телом, запрет разворота.
Вручную проверьте окно, клавиши, паузу и перезапуск. Анимация использует after,
а не sleep: интерфейс продолжает принимать события между ходами.
Координаты целочисленные, сложных математических формул нет.
